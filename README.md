# Classic Movies Quiz: privacy policy and help

The public privacy policy and support pages for the Classic Movies Quiz app, in English and Spain Spanish, served by GitHub Pages at https://jimkang12345-coder.github.io/classic-movies-quiz-privacy/.

- `privacy.html` and `privacidad.html`: privacy policy
- `index.html` and `soporte.html`: help and support

These files are built by `site/build.py --release` in the app repository (`jimkang12345-coder/Classic_App`, folder `site/`). Edit them there, rebuild, and copy `site/public/` here; don't edit them by hand.
